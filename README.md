# aegisflow
Stop letting your AI agents run blind. 🛡️⚡

AegisFlow is an open-source, zero-config AI Agent Firewall & Observability Proxy that runs 100% locally on your machine.
Swap a single base URL (localhost:4318/v1) to give LangChain, CrewAI, Claude Code, or any OpenAI-compatible agent instant real-time X-ray vision and security guardrails—without sending your sensitive prompts to a third-party SaaS.
• 🔍 Live Trace Waterfall: Watch every prompt, reasoning step, token count, and exact dollar cost stream live.
• 🛑 Auto-Redact & Block: Strip API keys, passwords, and prompt injections before they ever leave your laptop.
• ✋ 1-Click Human Approval: Pause dangerous tool calls (bash, sql_write, send_email) until you click Approve.
• ⏪ Time-Travel Replay: Edit any past prompt or tool output and replay from that exact step—no re-running the whole chain.
